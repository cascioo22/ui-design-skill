## Maintaining this package

When refreshing the skill:

1. Check the HIG home page and design "What's new" material for major restructuring.
2. Re-read `design-principles` first.
3. Compare change logs on the relevant foundation/component pages.
4. Update only the affected reference files.
5. Record the review date and package version in `CHANGELOG.md`.
6. Keep wording paraphrased; do not mirror Apple's documentation verbatim.
