## UI and interaction design

For substantial user-facing UI creation, modification, or review, use the `ui-design-skill` skill.

Apply its Human Interface Guidelines principles within this project's existing platform conventions and visual identity. Do **not** attempt to make the product look like an Apple app unless the project explicitly requires Apple-native visual conventions.

Before changing established UI patterns, inspect the existing shared components and the project-specific design guide. Prefer extending reusable patterns over adding one-off component variants.

Project-specific design decisions should live in `docs/design-system.md` (or the repository's equivalent), not in this global instruction block.
